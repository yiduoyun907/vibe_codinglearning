# 动手实验

<LessonMeta level="入门到进阶" minutes="约 3 小时" output="四份可验证的实验记录" prerequisite="完成对应课程" />

实验的目的不是「跟着做一遍」，而是让你在没有标准答案的情况下，独立完成一次判断。

## 实验规则

1. 每个实验都在独立的临时目录里做，不要拿正在维护的项目练手。
2. 先写验收标准，再让 AI 开始。
3. 每一步都留下可观察的结果：截图、命令输出或提交记录。
4. 实验结束后写一段复盘：哪里顺利、哪里卡住、下次怎么改。

## 记录模板

```markdown
# 实验记录：<实验名>

- 日期：
- 环境：
- 目标：

## 过程
1.
2.

## 结果
- 验收项 1：通过 / 未通过
- 验收项 2：通过 / 未通过

## 复盘
- 顺利的地方：
- 卡住的地方：
- 下次改进：
```

::: tip 不要在实验里使用真实数据
实验用假数据、临时目录和隔离环境。真实项目的数据、密钥和配置不要带进来。
:::
