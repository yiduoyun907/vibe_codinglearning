# 动手实验

<LessonMeta level="零基础到入门" minutes="约 3 小时" output="四份可验证的实验记录" prerequisite="完成对应课程" />

## 一句话理解

**课程告诉你「应该怎么做」，实验让你在临时目录里「真的做一遍」。**

实验不怕做错，怕的是只看不做。

## 实验规则

1. **在临时目录里做**：例如 `~/vibe-lab`，不要在正在维护的项目上练手。
2. **先写验收标准，再让 AI 开始**：否则你不知道什么时候算完成。
3. **每一步留下证据**：截图、命令输出或提交记录。
4. **结束后写复盘**：哪里顺利、哪里卡住、下次怎么改。

::: warning 不要在实验里使用真实数据
实验用假数据、临时目录和隔离环境。真实项目的数据、密钥和配置不要带进来。
:::

## 实验记录模板

```markdown
# 实验记录：<实验名>

- 日期：
- 环境：
- 目标：

## 过程
1.
2.

## 结果
- 验收项 1：通过 / 未通过
- 验收项 2：通过 / 未通过

## 复盘
- 顺利的地方：
- 卡住的地方：
- 下次改进：
```

## 卡住了怎么办

- **看不懂实验里的命令**：先查[编程与网站基础](/appendix/glossary-basics)。
- **命令报错**：把完整报错和刚才的操作一起发给 AI。
- **做不出完整功能**：先完成最小版本，例如只显示一条假数据。
- **担心改坏东西**：实验都在临时目录，先确认路径，再用 Git 存档。
