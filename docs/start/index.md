# 零基础开始

<LessonMeta level="入门" minutes="10" prerequisite="无" output="知道自己下一步该做什么" />

## 先说结论

你不需要先学会编程，才能开始用 AI 做东西。

但你需要慢慢学会三件事：

1. **把想法说清楚**：让 AI 知道你到底要什么。
2. **判断结果对不对**：不能只看「能不能运行」。
3. **出错时能退回来**：知道怎么恢复到上一个正常状态。

这三件事，就是本站要带你练的核心能力。

## 你不需要具备

- 不需要会写代码。
- 不需要英语很好。
- 不需要数学很好。
- 不需要懂终端、Git、部署这些词。

这些词和技能，本站都会从零解释。遇到不懂的，直接去[附录](/appendix/)查。

## 第一次打开本站，按这个顺序

1. 先读[什么是 Vibe Coding](/guide/core/what-is-vibe-coding)，知道自己在学什么。
2. 遇到看不懂的词，去[附录](/appendix/)查，不要硬撑。
3. 按[学习路线](/roadmap/)推进，一次只学一课。
4. 每课做完动手任务、通过验收清单，再点「标记完成」。

零基础第一次接触这些词，觉得陌生很正常。本站的写法是：先用一个生活化的比方让你理解，再给出准确解释。你不需要一次记住所有词。

## 三个安全习惯

从第一天就养成，能帮你避开绝大多数事故：

1. **先存档，再让 AI 改**：用 Git 保存一个可恢复的版本。
2. **不把密钥和真实数据贴进对话**：包括密码、Token、身份证号、客户资料。
3. **不确定就停**：先查、先问、先做小实验，不要赌。

## 常见担心

### 我英文不好怎么办？

工具界面可以翻译。代码里反复出现的英文单词，见多了自然会认识。本站会在第一次出现时解释，附录里也有单词表。

### 我会不会把电脑弄坏？

按本站步骤操作，只在临时文件夹里练习，不碰系统文件，不使用真实数据。学会 Git 之后，你还可以随时回滚。真正危险的是两件事：把密钥泄露出去，以及在真实数据上做实验。

### 我看不懂报错怎么办？

报错是线索，不是失败。把**完整报错**和**你刚才做了什么**一起发给 AI，让它解释。看不懂解释时，再让它用更简单的话说一遍。

### 我该先学哪个工具？

先用 Claude Code 走通一遍完整流程。工具会变，方法不会。等你理解了「需求 → 修改 → 验证 → 回滚」，换其他工具会很快。

### 我每天只有半小时，能学会吗？

能。把一课拆成两三次完成，每次只做一个动手任务。不要追求一次学完，追求每次都有一个可验证的小结果。
