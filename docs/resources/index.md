# 资源索引

<LessonMeta level="全阶段" minutes="按需查阅" output="一份持续维护的可信资源清单" prerequisite="无" />

资源清单的原则：

- **优先一手来源**：官方文档、原始论文、作者原文。
- **标注时效**：工具类内容变化快，记录查阅日期。
- **少而精**：收藏不等于掌握，能用一个就不收藏十个。

:::

## 自己的资源库

随着实践推进，补充三类内容：

- **项目复盘**：哪些做法在真实项目中有效；
- **事故记录**：哪些反模式造成过实际损失；
- **可复用模板**：SPEC、CLAUDE.md、任务交接笔记。

模板建议放在仓库的 `templates/` 目录，而不是散落在聊天记录里。
