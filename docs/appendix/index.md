# 附录

<LessonMeta level="全阶段" minutes="按需查阅" output="遇到不懂的词时能快速查到准确解释" prerequisite="无" />

这里不要求你从头读到尾，而是**遇到不懂的词时回来查**。

每个词尽量按同样的方式解释：

- **一句话**：先给你一个能记住的说法。
- **打个比方**：用生活中的例子帮助理解。
- **准确地说**：保留专业定义，避免理解偏差。
- **常见误解**：指出最容易搞错的地方。

## 查词方法

1. 先在本页的分类里找。
2. 找不到就用站内搜索，输入你看到的词。
3. 还是没有，就把词发给 AI，并加一句：

> 请用零基础能听懂的话解释这个词，先给一个生活化的比喻，再给准确的定义，最后说明它在我当前任务里意味着什么。

::: warning 术语会变化
工具类术语（例如某个按钮叫什么、某个命令怎么写）会随版本变化。遇到和课程描述不一致的地方，以官方文档为准，并把差异记录到[学习日志](/log/)。
:::
