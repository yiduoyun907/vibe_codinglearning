# 项目 01 · 阅读清单

<LessonMeta level="实战" minutes="约 5 小时" prerequisite="完成实验 01–03" output="一个部署后可访问的阅读管理应用" />

## 目标

做一个自己会用的阅读清单：记录想读的文章，标记已读，按状态筛选，数据保存在本地。

这个项目故意不引入后端。先把前端、存储、错误处理和部署走通，再考虑服务端。

## 功能范围

包含：

- 添加文章（标题、链接）；
- 标记已读 / 未读；
- 按「全部 / 未读 / 已读」筛选；
- 删除文章；
- localStorage 持久化；
- 移动端可用；
- 部署到静态托管平台。

不包含：

- 用户账号与多设备同步；
- 网页内容抓取；
- 标签体系；
- 导入导出。

## 里程碑

| 阶段 | 内容 | 验收 |
| --- | --- | --- |
| M1 | 静态列表 + 添加 | 能添加并显示，空输入被拒绝 |
| M2 | 已读切换 + 筛选 | 三种筛选结果正确，刷新后状态保留 |
| M3 | 删除 + 错误处理 | 删除有确认；存储失败有提示且状态回滚 |
| M4 | 部署 | 公网地址可访问，移动端布局不溢出 |

## 建议的 SPEC 要点

- 数据结构：`id`、`title`、`url`、`read`、`createdAt`；
- 存储键名带版本，例如 `reading-list:v1`；
- 链接需要基本校验，拒绝 `javascript:` 等危险协议；
- 数据损坏时回退为空列表，不阻塞渲染；
- 删除操作需要二次确认；
- 筛选状态可以不持久化，但要写入 URL 查询参数（可选进阶）。

## 验收标准

- Given 空输入 When 点击添加 Then 不新增记录，并显示提示
- Given 合法输入 When 添加 Then 列表顶部出现新记录
- Given 未读记录 When 勾选 Then 进入已读状态，筛选结果同步变化
- Given 已读记录 When 刷新页面 Then 状态保持
- Given 存储写入失败 Then 状态回滚并显示错误
- Given 删除记录 Then 需要确认，取消则不删除
- Given 375px 宽度 Then 页面无横向滚动
