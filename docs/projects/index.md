## 项目流程

每个项目都按同一套流程推进：

1. **写 SPEC**：范围、流程、数据、验收标准。
2. **建基线**：Git 初始化，提交最小可运行版本。
3. **切片实现**：每个切片可验证、可提交、可回滚。
4. **独立验收**：逐条运行验收标准，记录结果。
5. **部署**：让项目离开本地，接受真实环境检验。
6. **复盘**：写下偏差、事故和下次改法。

::: warning 项目不是教程复刻
不要照着步骤复制。每个项目至少做一次自己的取舍：改一个需求、换一种数据存储、加一个错误场景。只有你做过决定，项目才算你的。
:::
