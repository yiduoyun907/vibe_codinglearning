## 这个站怎么用

这不是资料收藏夹，而是一个训练闭环：

1. **读认知部分**：明确这一课要产出什么，而不是「大概了解一下」。
2. **完成动手任务**：以验收清单为准，不以读完为准。
3. **标记完成**：路线页会自动汇总进度。
4. **写复盘**：把踩坑记录进反模式库，把有效做法沉淀成规格模板。

::: tip 建议节奏
每周投入 5–7 小时。先按「认知 → 工具 → 规格」走完一轮，再进入迭代与工程化阶段。
:::

## 当前覆盖

| 阶段 | 主题 | 产出 |
| --- | --- | --- |
| 一 | 认知基础 | 能判断什么任务适合交给 AI，什么必须自己把关 |
| 二 | 工具链 | 跑通 Claude Code、终端与 Git 的最小工作流 |
| 三 | 提示与规格 | 写出可执行的规格和项目上下文文件 |

首批 11 节课，预计约 5 小时。后续阶段会在实践中逐步补齐。

## 内容原则

- 每课必须有一个可验证的产出。
- 优先记录真实踩坑，而不是搬运二手结论。
- 先写自用版本，成熟后再整理为公开教程。
- 不追求工具评测的时效性，优先沉淀稳定的方法和判断。
