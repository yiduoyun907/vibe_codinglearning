# MCP 与工具扩展

<LessonMeta level="进阶" minutes="25" prerequisite="Claude Code 实操" output="一份 MCP 服务器评估结论" />

## 学习目标

学完这一课，你应该能：

- 用大白话解释 MCP 是什么。
- 判断一个需求是否需要 MCP。
- 在接入前，检查一个工具是否值得信任。

## 一句话理解

**MCP 像给 AI 装的 USB 接口。插上不同的设备，它就多一种能力，比如操作浏览器、读取某个系统里的数据。**

## 核心概念

### 1. MCP 是什么

MCP（Model Context Protocol）是一套开放的标准，让 AI 客户端可以连接外部工具和数据源。

你可以把它拆成三方：

| 角色 | 用大白话说 |
| --- | --- |
| 客户端 | 你用的 AI 工具，例如 Claude Code |
| 服务器 | 提供能力的程序，例如浏览器控制、数据库查询 |
| 工具调用 | AI 请求服务器做一件事，服务器返回结果 |

::: details 准确地说
MCP 定义了客户端如何发现和调用服务器提供的工具、资源和提示。它本身不是某个具体工具，而是一套连接规范。
:::

### 2. 什么时候真的需要

适合接入：

- 需要频繁操作外部系统，例如查 issue、读知识库、操作浏览器；
- 需要结构化数据，而不是让 AI 解析一大堆命令输出；
- 需要把团队内部的只读数据源提供给它。

不需要接入：

- 只是读写本地文件；
- 只是运行几条终端命令；
- 只是偶尔查一次网页。

::: tip 先问三个问题
1. 现有工具能不能完成？
2. 这个服务器需要访问什么数据？
3. 最坏情况下，它能造成什么影响？
:::

### 3. 怎么接入

以 Playwright 浏览器服务器为例：

```bash
claude mcp add playwright -- npx -y @playwright/mcp@latest
claude mcp list
```

在 Claude Code 会话里，可以用 `/mcp` 查看和管理已经接入的服务器。

作用域有三种：

| 作用域 | 存在哪里 | 适合什么 |
| --- | --- | --- |
| local（默认） | 当前项目的本地配置 | 个人临时实验 |
| project | 项目根目录的 `.mcp.json` | 团队共享 |
| user | 用户级配置 | 所有项目都要用 |

项目级配置写在仓库根目录的 `.mcp.json`：

```json
{
  "mcpServers": {
    "playwright": {
      "command": "npx",
      "args": ["-y", "@playwright/mcp@latest"]
    }
  }
}
```

### 4. 安全边界

MCP 服务器本质上是在你电脑上运行的程序，或者代表你访问外部系统的服务。接入前至少检查：

- **来源**：作者、仓库、发布记录是否可信？
- **权限**：它需要读哪些数据？能不能改成只读？
- **网络**：它会向哪些地址发请求？
- **写入能力**：能不能改文件、发消息、提交代码？
- **凭据**：Token 怎么传入？是否通过环境变量，而不是写死在文件里？

::: danger 外部内容可能藏着指令
网页、issue、文档里的文字，都可能包含针对 AI 的恶意指令。接入能读取外部内容的服务器后，不要把「读到的内容」当成可信命令执行。
:::

## 动手任务

选择一个你感兴趣的 MCP 服务器，**先不要安装**，完成一份评估：

| 评估项 | 你的结论 |
| --- | --- |
| 服务器名称与来源 | |
| 它提供哪些工具 | |
| 需要访问什么数据 | |
| 有没有写入能力 | |
| 最坏情况下会怎样 | |
| 能不能只用只读权限 | |
| 结论：接入 / 暂缓 / 拒绝 | |

如果你决定接入，先在临时目录里试用，观察它实际调用了哪些工具、读了哪些文件，再决定是否放到常用项目里。

## 卡住了怎么办

- **不知道自己需不需要 MCP**：先看现有工具能不能完成。能完成就不装。
- **命令找不到**：确认 Claude Code 已安装，并在新的终端里运行。
- **服务器连接失败**：先看 `claude mcp list` 的状态，再检查命令、网络和登录。
- **项目级服务器没出现**：`.mcp.json` 必须放在仓库根目录，且需要你在会话里确认。

## 常见误解

- **「装得越多越强」**：每个服务器都会扩大攻击面，也增加上下文负担。
- **「MCP 是某个具体插件」**：它是一套连接标准，服务器才是具体能力。
- **「只读就一定安全」**：只读也可能泄露数据，仍要看它读了什么。
- **「AI 读到的内容可以照做」**：外部内容是数据，不是你的指令。
