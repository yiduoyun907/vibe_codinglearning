# 课程总览

<LessonMeta level="零基础到入门" minutes="约 5 小时" output="完成首批课程并留下可验证的练习记录" prerequisite="无" />

首批课程只聚焦三件事：**建立正确认识、跑通工具、学会把需求说清楚**。这三件事决定了你之后能走多远。

## 如果你完全零基础

按下面的顺序读，不要跳：

1. [零基础开始](/start/)：先知道要准备什么。
2. [什么是 Vibe Coding](/guide/core/what-is-vibe-coding)：先搞清楚自己在学什么。
3. [心智模型](/guide/core/mental-model)：记住「意图 → 规格 → 执行 → 验收」四步。
4. [Claude Code 实操](/guide/tools/claude-code)：把工具跑起来。
5. 其余课程按阶段顺序推进。

遇到不认识的词，直接查[术语附录](/appendix/)，不用停下来从头补编程课。

## 每课怎么学

每一课都按同样的节奏设计：

1. **先看「一句话理解」**：用最短的话知道这一课在讲什么。
2. **读核心概念**：注意生活化的比方，再看「准确地说」。
3. **做动手任务**：必须在自己电脑上完成，不要只看。
4. **对验收清单**：全部通过，再点「标记完成」。
5. **记下卡住的地方**：写进[学习日志](/log/)，下次会更快。

::: tip 读完不算完成
本站以「你能不能做出来」为标准，不以阅读进度为标准。看不完可以分两次，但动手任务不能跳过。
:::

## 本站怎么讲一个概念

重要的概念尽量按四步讲：

1. **一句话**：先给你一个能记住的说法。
2. **打个比方**：用生活中的场景建立直觉。
3. **准确地说**：保留专业定义、前提和边界。
4. **常见误解**：指出最容易搞错的地方。

这样做是为了同时满足两件事：**先看懂，再校准**。简单的话负责降低门槛，准确的定义负责防止理解跑偏。

## 每课的固定结构

所有课程使用同一套结构，方便你快速定位：

1. **学习目标**：这一课结束后你能做什么。
2. **一句话理解**：先用最简单的话说明核心。
3. **核心概念**：不超过五个，配生活化的比方和准确解释。
4. **动手任务**：必须在自己环境里完成的动作。
5. **验收清单**：判断是否真正掌握的硬标准。
6. **常见误解**：最容易搞错的地方。
7. **本课术语**：这一课出现的关键词，链接到附录。
8. **延伸阅读**：想深入时的方向。

## 学不会怎么办

- **看不懂概念**：先看「打个比方」，再看「准确地说」，最后查附录。
- **命令报错**：把完整报错和刚才的操作一起发给 AI。
- **动手卡住**：回到验收清单，找到最小的一步，只完成那一步。
- **失去方向**：回到[学习路线](/roadmap/)，看当前阶段和下一步。
