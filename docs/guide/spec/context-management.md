# 上下文管理

<LessonMeta level="进阶" minutes="25" prerequisite="Claude Code 实操" output="一次干净的上下文交接" />

## 学习目标

学完这一课，你应该能：

- 认出上下文里的三类「噪音」。
- 判断什么时候该清空、什么时候该压缩。
- 用一份交接笔记，让新会话快速接上进度。

## 一句话理解

**上下文是 AI 的工作台。桌面上堆的东西越多，它越难找到当前任务需要的那张纸。**

## 核心概念

### 1. 上下文里都有什么

AI 每次能看到的，包括：

- 工具预先写好的规则；
- 你们当前的对话；
- 你引用的文件和粘贴的代码；
- 命令输出、报错和工具结果。

这些内容共享同一个「桌面面积」。无关内容越多，关键内容越容易被淹没。

::: details 准确地说
上下文窗口有 token 上限。系统提示、对话历史、文件内容和工具输出都会占用额度。超过上限后，较早的内容可能被压缩或丢弃。
:::

### 2. 三类污染

| 类型 | 例子 | 后果 |
| --- | --- | --- |
| 无关信息 | 同一会话里讨论三个不相关的任务 | AI 抓错重点 |
| 过期信息 | 早期方案已经废弃，但还留在对话里 | AI 参考旧方案 |
| 错误信息 | 一次失败的尝试没有被标记 | AI 沿着错误路径继续 |

清理上下文的目的，不是「省 token」，而是**保证 AI 看到的是当前有效的信息**。

### 3. 四种管理动作

| 动作 | 什么时候用 | 怎么做 |
| --- | --- | --- |
| 精确引用 | 需要某个文件 | 用 `@文件路径`，不要整段粘贴 |
| 清理 | 切换到不相关的任务 | `/clear` |
| 压缩 | 同一任务但历史太长 | `/compact`，保留摘要 |
| 交接 | 需要跨会话继续 | 写一份状态笔记，再开新会话 |

### 4. 写一份交接笔记

清空上下文前，把状态写成一个文件或一段可复制的文本：

```markdown
# 任务交接

## 目标
<这次要实现什么，验收标准是什么>

## 已完成
- <改动 1，对应文件>
- <改动 2，对应文件>

## 当前状态
- 可以运行 / 有报错：<具体报错>
- 已验证：<验证方式与结果>

## 下一步
- <最小下一步动作>

## 约束与禁忌
- <不能改的文件、不能引入的依赖、已知坑>

## 相关文件
- <文件路径>
- <文件路径>
```

有了它，新会话不需要重新读完整段历史，也能快速进入状态。

### 5. 把稳定知识移出对话

对话是临时的，项目知识应该是持久的：

| 内容 | 放在哪里 |
| --- | --- |
| 长期规则 | `CLAUDE.md` |
| 功能规格 | `docs/spec/` |
| 决策记录 | 简短的日志或说明 |
| 一次性尝试 | 留在当前会话，结束后丢弃 |

::: tip 一个判断
如果一条信息下周还会用到，就不要只把它留在聊天记录里。
:::

### 6. 控制工具输出的噪音

AI 读文件、跑命令时，输出也会进入上下文。减少噪音的方法：

- 先搜索，再读取相关片段，不要读整个大文件；
- 命令输出加过滤，例如只看错误行或最后几十行；
- 避免读取 `node_modules`、构建产物、完整日志；
- 大范围调研可以交给子代理，只把结论带回主会话。

## 动手任务

1. 找一个已经进行很久的 AI 会话。
2. 按上面的模板写一份交接笔记。
3. 执行 `/clear`，把交接笔记作为新会话的第一条消息。
4. 观察新会话是否还需要你重复解释背景。
5. 对比清理前后，AI 的回答质量和速度有什么变化。

## 验收清单

- [ ] 能说出三类上下文污染，并各举一个例子。
- [ ] 知道 `/clear` 和 `/compact` 分别什么时候用。
- [ ] 能写出别人（或新的 AI 会话）看得懂的交接笔记。
- [ ] 会把长期规则放进 CLAUDE.md，而不是依赖对话记忆。
- [ ] 能让 AI 只读目标片段，而不是整个大文件。

## 卡住了怎么办

- **不知道什么时候清空**：换任务就清空。拿不准时，先写交接笔记再清。
- **清空后 AI 又忘了**：说明关键信息没有写进交接笔记或 CLAUDE.md。
- **对话太长但不想丢细节**：先写交接笔记，再 `/clear`，比只 `/compact` 更稳。
- **AI 读了大文件后答非所问**：让它先总结，再只引用相关片段。

## 常见误解

- **「把整个仓库塞进去更保险」**：噪音大、成本高，关键信息反而被淹没。
- **「压缩等于清空」**：压缩保留摘要，清空是重新开始。
- **「AI 应该记得上次说的」**：跨会话没有记忆，重要决定要写下来。
- **「失败尝试不用管」**：AI 可能继续沿着错误假设推理。
- **「工具输出越多越好」**：输出也是上下文，会挤占空间。
