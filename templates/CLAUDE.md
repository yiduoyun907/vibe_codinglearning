# 项目概览

一句话说明这个项目是什么、给谁用。

# 常用命令

- 安装依赖：`npm install`
- 本地开发：`npm run dev`
- 运行测试：`npm test`
- 构建：`npm run build`

# 架构与目录

- `src/`：业务代码
- `src/api/`：接口层，不直接操作数据库
- `docs/`：设计文档

# 代码约定

- 使用 ES modules，不使用 CommonJS
- 组件文件名使用 PascalCase
- 新增依赖前先确认现有依赖能否满足

# 禁止事项

- 不要修改 `src/generated/`，它由代码生成
- 不要提交 `.env` 或任何密钥
- 不要直接编辑已合并的数据库迁移文件，新增迁移代替

# 已知坑

- 测试前必须设置 `NODE_ENV=test`，否则会连接开发数据库
- Windows 上路径使用正斜杠

# 维护原则

- 只写删掉后会让 AI 更容易犯错的内容
- 控制在 100 行以内
- 每次 AI 犯错后，判断是否值得沉淀为一条规则
